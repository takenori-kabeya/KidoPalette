# KidoPalette ヘルプ

KidoPalette は macOS 向けのアプリランチャーです。使うアプリを登録し、タブでまとめ、ホットコーナーからパレットを開けます。

## はじめに

1. ランチャーを開きます（ホットコーナー、Dock に表示している場合はそのアイコン、または **ウィンドウ → Toggle Visibility**／⌘⇧L）。
2. **アプリを追加** から `.app` を選ぶか、Finder からランチャーへドラッグ＆ドロップします。
3. タブでアプリをグループ分けします。タブ名をダブルクリックすると名前を変更できます。

## ホットコーナー

- **設定** でトリガーするコーナーと、ホットコーナーの有効／無効を選べます。
- **フルスクリーンで表示** をオンにすると、メニューバーや Dock より手前まで画面を覆います。
- 設定したコーナーにポインタを入れると、ランチャーの表示／非表示が切り替わります。

## アプリとタブ

- アイコンをクリックするとアプリを起動し、ランチャーは隠れます。
- アイコンをドラッグして並べ替えたり、アイコンの間にドロップして挿入したりできます。
- Finder の `.app` を最後のアイコンより後ろの空きへドロップすると末尾に追加され、挿入ギャップへドロップするとその位置に入ります。
- コンテキストメニューから別タブへ移動、または登録解除できます。
- タブバーからタブの追加・改名・並べ替え・削除ができます（タブは最低1つ残ります）。

## 設定

メニューバー（**KidoPalette → 設定…**）またはランチャー内の歯車から開けます（Dock 非表示時にも便利です）。

- ホットコーナーのオン／オフ、コーナー選択、フルスクリーン表示
- Dock に表示

## App Sandbox について

公式ビルドは **App Sandbox** 下で動作します。Open Panel やドラッグ＆ドロップで追加したアプリへのアクセスは、セキュリティスコープ付きブックマークとして保存され、再起動後も使えます。
